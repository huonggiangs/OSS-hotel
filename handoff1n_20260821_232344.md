## Trạng thái môi trường

Tất cả container OSS đang `healthy` tại thời điểm bàn giao:

| Thành phần | Địa chỉ |
|---|---|
| Webadmin | `http://localhost:3000` |
| Property Web | `http://localhost:3100` |
| Edge Node | `http://localhost:4200` |
| API Webadmin / Property | `4000` / `4100` |
| Channel / AI Pricing / IoT / CRM | `4101`–`4104` |

Chạy hằng ngày từ `D:\hotel\OSS`:

```powershell
.\ops\scripts\Start-Oss.ps1
.\ops\scripts\Get-OssStatus.ps1
.\ops\scripts\Stop-Oss.ps1
```

`Start-Oss.ps1` đã được chạy lại hai lần liên tiếp thành công, xác nhận seed và startup idempotent.

Docker Desktop tự ghi đè cấu hình AutoStart trực tiếp; tạo Scheduled Task bị Windows từ chối quyền. Thay vào đó, file Startup theo tài khoản đã được tạo tại:

`C:\Users\16flip\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\OSS-Start-Docker-Desktop.cmd`

File này mở Docker Desktop lúc đăng nhập; các container dùng `restart: unless-stopped` nên tự lên lại. Không tác động các container Docker khác trên máy.
